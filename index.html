              Metodologia e limitações

                Usuários do painel

                Usuário novo entra com o e-mail e a senha padrão e cria a própria senha no primeiro acesso. "Resetar senha" volta para a senha padrão.

                Regiões de cada gerente

                Marque as regionais que cada gerente enxerga. É a equipe dele: o painel inteiro (números, mapa, clientes, agenda) passa a mostrar só essas regionais para ele. Admin e diretoria veem tudo.

                Atualizar as bases

                Solte aqui as duas exportações do C4C, no mesmo formato de setembro. As visitas são casadas com os questionários pelo ID da visita; uma visita que já existe é atualizada (status, check-in, notas), e as novas entram.
